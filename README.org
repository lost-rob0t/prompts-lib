#+title: prompts-lib
#+description: Org-first reusable prompt library shared by Emacs and other LLM clients.

* Purpose

This repository is the durable source of truth for reusable user prompts.
Clients render and execute prompts; they do not own prompt content.

The library is deliberately file-native.  There is no JSON catalog or prompt
database.  Metadata and prompt text live together in files that remain useful
outside any client.

* Formats

Org is the default and canonical format.

A normal prompt looks like:

#+begin_src org
#+title: Implement bounded slice
#+prompt_id: engineering.implement-slice
#+description: Inspect first, implement narrowly, verify exact head.
#+filetags: :engineering:implementation:tdd:git:
#+prompt_aliases: implement | coding task | bounded slice

* Prompt
Work in {{REPO}}.
...
#+end_src

Prompt fields use:

- ={{NAME}}= — required value
- ={{NAME|default value}}= — value with a default

Clients should also support Markdown and declarative Lisp records when useful,
but new prompts default to Org.  Format adapters must project into the same
logical record: ID, title, description, tags, aliases, and prompt body.

* Initial prompts

The initial Org library captures recurring engineering, research, symbolic
verification, writing, and StarIntel visual workflows.  Files are individually
addressable and can be linked from other Org documents with normal =file:=
links.

=engineering.state-machine-worker= captures the evidence-driven continuous
worker pattern: each loop persists =WORKER_STATE= and chooses the next
=RESEARCH=, =IMPLEMENT=, or =REVIEW= mode from the evidence produced by the
previous pass.

See =docs/ADARD.org= for the architecture decision.

* CLI

The small file-native CLI provides non-Emacs list/show/copy access to canonical
Org prompts:

#+begin_src sh
python3 bin/prompt-lib list
python3 bin/prompt-lib show engineering.state-machine-worker
python3 bin/prompt-lib cp engineering.state-machine-worker
python3 bin/prompt-lib cp engineering.state-machine-worker --set REPO=lost-rob0t/zara
#+end_src

=cp= copies to the system clipboard using =wl-copy=, =xclip=, or =xsel=, in
that order.  Supplied =--set NAME=VALUE= values and prompt defaults are rendered
before copy; unresolved required placeholders remain visible rather than being
silently invented.

Set =PROMPTS_LIB_DIR= when the command is installed somewhere other than the
repository checkout.

* Emacs

The Emacs client lives in the dotfiles repository under
=lisp/llm/prompt-lib.el=.

Its default checkout path is:

#+begin_example
~/Documents/Projects/prompts-lib
#+end_example

Override that with =PROMPTS_LIB_DIR=.  Once the checkout exists, =SPC y p=
opens the prompt-library Transient.  Prompts can be browsed, previewed, copied,
inserted, edited, or sent through gptel.

The Qtile integration can also open the Emacs prompt browser directly through
=Super e y p=.  In the browser, =c= copies the rendered prompt to the kill ring
and system clipboard.

New prompts should open in Org mode by default.  Markdown and Lisp are explicit
alternate formats rather than separate libraries.
